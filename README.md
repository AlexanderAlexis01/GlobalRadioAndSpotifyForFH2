# SlopInstallation
Install [FH2_ModLoader of Bulelt4Fun](https://github.com/Bullet4fun/FH2_ModLoader): put its `azimuth-tls.dll` in `data\bin\` of the azimuth's loader (just make sure to make a backup please)
Put `FH2_SpotifyMin.dll` in `data\bin\mods\`, and `HUD_RadioIcon_Global.swatchbin` in `data\bin\mods\FH2_SpotifyMin\`.
For `librespot` and `both` (which are few modes that i linked upon, basically needed to make spotify work) put `librespot.exe` in `data\bin\mods` 
Start the game through Azimuth and enjoy.
# Config stuff
Open `data\bin\mods\FH2_SpotifyMin\FH2_SpotifyMin.ini` (it shouuuld be creating itself when you start up the game for the first time)
On `source=` u can choose from `librespot`(spotify, will show a device on devices u connect, needs premium KEK ), `radio`, `both` and `folder`,
`librespot` is used to connect to spotify, `Radio` to listen to some global live radio, `both` is to listen spotify AND the radio, `folder` is to put ur own music (it can only load mp3, flac and wav files).
